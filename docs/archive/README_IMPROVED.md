## 🌟 Giới thiệu

**AnkiAI ImageAddon** là add-on mạnh mẽ giúp bạn tự động thêm ảnh và GIF vào Anki flashcards:

### Tại sao nên dùng AnkiAI?

| Tính năng | Mô tả | Lợi ích |
|-----------|-------|---------|
| ✨ **AI Image Generation** | Google Imagen tạo ảnh từ text | Ảnh độc quyền, creative |
| 🔍 **Smart Image Search** | 20+ providers (Pexels, Unsplash, etc.) | Miễn phí, chất lượng cao |
| 🎬 **Animated GIFs** | 5 GIF platforms chuyên nghiệp | Tăng memory retention |
| 🤖 **AI Keywords** | ChatGPT/Gemini tự động tạo query | Tìm ảnh chính xác hơn |
| ⚡ **Batch Processing** | Xử lý 100-1000 thẻ cùng lúc | Tiết kiệm thời gian |
| 📊 **Progress Tracking** | Real-time progress & logs | Theo dõi chi tiết |
| 🛡️ **Privacy First** | API keys lưu local | An toàn tuyệt đối |
